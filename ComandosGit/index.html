Comandos Git

Guia rápido dos principais comandos Git

Branches Checkout / Switch Merge Repositórios Remotos Histórico Tags Undo / Reset / Revert Auxiliares

1. Criação e Gestão de Branches

git branch

Lista todas as branches locais existentes no repositório.

git branch <nome-da-branch>

Cria uma nova branch a partir do estado atual, sem alternar para ela.

git branch -a

Lista todas as branches, tanto locais quanto remotas.

git branch -d <nome-da-branch>

Exclui uma branch local que já foi integrada (merged).

git branch -D <nome-da-branch>

Força a exclusão de uma branch local, mesmo que contenha alterações não integradas.

2. Navegação e Alternância (Checkout / Switch)

git checkout <nome-da-branch>

Alterna a área de trabalho para a branch especificada.

git checkout -b <nome-da-branch>

Cria uma nova branch e alterna para ela imediatamente.

git switch <nome-da-branch>

Alterna para a branch especificada usando o comando mais moderno.

git switch -c <nome-da-branch>

Cria uma nova branch e alterna para ela imediatamente.

3. Integração de Alterações (Merge)

git merge <nome-da-branch>

Integra o histórico e as alterações da branch informada à branch atual.

git merge --abort

Cancela uma operação de merge em andamento e restaura o estado anterior.

4. Sincronização com Repositórios Remotos

git push origin <nome-da-branch>

Envia os commits locais da branch para o repositório remoto.

git fetch

Baixa informações e novos commits do repositório remoto sem alterar os arquivos locais.

git pull

Busca alterações remotas e as integra imediatamente à branch atual.

5. Visualização de Histórico e Logs

git log

Exibe o histórico detalhado de commits, incluindo autor, data, hash e mensagem.

git log --oneline

Exibe o histórico de commits de forma resumida.

git log --graph --all

Exibe uma representação gráfica em texto do fluxo das branches do projeto.

6. Marcadores e Versões (Tags)

git tag

Lista todas as tags existentes no repositório.

git tag <nome-da-tag>

Cria uma lightweight tag apontando para o commit atual.

git tag -a <nome-da-tag> -m "<mensagem>"

Cria uma annotated tag contendo informações como autor, data e mensagem.

git push origin <nome-da-tag>

Envia uma tag específica para o repositório remoto.

git push origin --tags

Envia todas as tags criadas localmente para o repositório remoto.

7. Correção e Restauração de Erros

git checkout -- <arquivo>

Desfaz alterações não salvas no arquivo, restaurando a versão do último commit.

git restore <arquivo>

Restaura o arquivo do working directory para o estado do último commit.

git restore --staged <arquivo>

Remove o arquivo da staging area, desfazendo o git add e mantendo as alterações.

git reset --soft <hash-do-commit>

Volta o histórico até o commit especificado, preservando as alterações na staging area.

git reset --mixed <hash-do-commit>

Volta o histórico, desfaz a staging area e mantém as alterações nos arquivos.

git reset --hard <hash-do-commit>

Desfaz completamente as alterações locais e altera o histórico. Operação destrutiva.

git revert <hash-do-commit>

Cria um novo commit que desfaz as alterações do commit informado, preservando o histórico original.

8. Comandos Auxiliares

git add .

Adiciona arquivos modificados à staging area.

git add <arquivo>

Adiciona um arquivo específico à staging area.

git commit -m "<mensagem>"

Registra as alterações da staging area no histórico local.
