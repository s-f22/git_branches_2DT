Sobre a página

O HTML é utilizado para estruturar o conteúdo de uma página web, enquanto o CSS é utilizado para definir sua aparência.

Algumas tecnologias:

  • HTML
  • CSS
  • JavaScript (Logo mais 😎)

Passos para criar uma página:

  1. Criar o arquivo HTML
  2. Criar o arquivo CSS
  3. Linkar o CSS ao HTML
